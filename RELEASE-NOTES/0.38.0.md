bdi 0.38.0

Minor release, **0.37.0 → 0.38.0**.

## Highlights

**`bdi watch` hears a write to a tracker within seconds, with nothing else running.** Give a project's entry `serve = "127.0.0.1:8742"`, the address its `bd serve` listens on, and the watcher follows that tracker's event stream. A write from any bd client then reaches every watching agent and script within seconds. A project without `serve` is polled as before.

**A deferred bead is sent again when its date arrives.** Each bead line from the watcher now carries `defer_until_reached`, which turns true once the bead's `defer_until` has passed, so whatever waits on a deferred bead hears when it comes due.

**`bdi gates` tells failing and passing checks with a fine-grained token.** Where GitHub refuses the token a commit's check runs, as it does on a private repository, `bdi gates` reads the commit's workflow runs and statuses instead. Give the token *Actions* read access for this.

**bdi exits cleanly when its terminal or its reader goes away.** Closing the pane under a running bdi no longer makes it abort, and `bdi --beads` piped into a command that stops reading early now just stops.

## Upgrading

**The event stream needs bd's events journal turned on where `bd serve` runs.** Nothing polls a project while its stream is down, so it shows as stale once `covered_for_seconds` passes.

## Maintenance

A fix to how the watcher reports a tracker outage, faster and leaner tests, documentation, and dependency bumps.
