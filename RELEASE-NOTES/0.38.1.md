bdi 0.38.1

Patch release, **0.38.0 → 0.38.1**.

## Highlights

**`bdi watch` says when a project whose event stream is down has gone stale.** Its freshness line now carries `lapsed`, sent the moment `covered_for_seconds` passes with nothing vouching for the project, and sent again as `false` once the stream comes back. Before, the watcher's consumers just stopped hearing about that project.

**`bdi gates` reports failing and passing checks on more fine-grained tokens.** A token refused each check run on its own, rather than all of them at once, now falls back to the commit's workflow runs and statuses as well.

## Maintenance

Tests for a pull request that merged while `bdi gates` was stopped, and for one unreadable tracker among several.
