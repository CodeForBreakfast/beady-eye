bdi 0.15.0

Minor release, **0.14.0 → 0.15.0**.

## Highlights

**A bead named on the command line is the only tree its project draws.** `bdi arkham:ark-12` used to add that tree to everything `bdi` discovered, so there was no way to ask for one tree on its own. Now it draws in place of every other tree of its project, including the roots your config names there. Other projects are read and discovered as before. If you want a tree drawn alongside the rest, name it under `[roots.explicit]` in your config rather than on the command line.

**A search that lands under a folded run opens only the way down to what it found,** rather than the finished work under every ancestor on the way.

**The bead window's dates sit on two rows,** created and updated above started and closed, so the last date is no longer cut off in a narrow window.

**A link drawn in several places lights up everywhere at once** when you hover it, in terminals that group OSC 8 links.
