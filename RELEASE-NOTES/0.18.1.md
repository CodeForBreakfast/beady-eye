bdi 0.18.1

Patch release, **0.18.0 → 0.18.1**.

## Highlights

**Reading a blocker's project no longer draws all of that project.** When bdi reads another project to show a blocker, it now draws only the blocker and the beads under it or blocking it, not every tree in that project. Before this, one blocking edge could make bdi read and draw most of your configured projects. Nothing to do.

## Maintenance

More tests around reading a blocker's project.
