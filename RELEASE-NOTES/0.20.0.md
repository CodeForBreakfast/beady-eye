bdi 0.20.0

Minor release, **0.19.0 → 0.20.0**.

## Highlights

**A one-shot read is faster.** `bdi --beads` and `bdi --json` now ask a tracker for its beads at once instead of one call after another, and no longer ask for a fingerprint nobody compares. The answers are the same as before apart from `generated_at`. Nothing to do.

**`bdi listen` holds every project's beads on a socket.** It reads each configured project the way the view does, with no view, and takes producers' lines on `$XDG_RUNTIME_DIR/beady-eye/listener.sock`. A second `bdi listen` exits non-zero and names the socket. Nothing reads what it holds yet, so run it only if you are building on it. The README and `docs/configuration.md` have a systemd user unit and a launchd agent.

## Maintenance

The design for the change listener is written up, and the refresh code moved out of the terminal layer.
