bdi 0.27.0

Minor release, **0.26.0 → 0.27.0**. Nothing needs changing to upgrade. To read a tracker from a host with no checkout of its project, read the first highlight.

## Highlights

**A project with no checkout can still be read.** A `[[projects]]` entry can name its tracker's `database` in place of a `path`, and a new `[dolt]` table names the Dolt server it sits on, so a host that holds none of a project's checkouts still draws its trees. The board, the watcher and both pseudopods all read it. The [configuration reference](https://github.com/CodeForBreakfast/beady-eye/blob/main/docs/configuration.md) has the tables.

**`bdi gates` settles a wait on an issue or a release.** A `gh:issue` gate closes once its issue closes, and a `gh:release` gate closes once its repository publishes a release after the gate was made. Both close on the same look that settles pull-request gates.

**A focused board draws only the focused work.** Under `F`, or a bead named on the command line, the line that stood for the project's other trees and counted their agents and anomalies is gone, and going to or searching for a bead outside the focus finds nothing. `F` again puts the whole forest back. A focused board builds only what it draws, so it spends less CPU and holds less memory.

**`bdi bd` writes only to the project's own tracker.** It no longer passes on the `BEADS_` and `BD_` variables its caller exported, bar the credential and the actor, so an exported database cannot redirect the answer it carries. What entering the project's directory sets still reaches bd.
