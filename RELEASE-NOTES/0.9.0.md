bdi 0.9.0

Minor release, **0.8.0 → 0.9.0**.

## Highlights

**Nix users no longer compile bdi.** CI pushes every `main` build for x86_64 Linux to the `codeforbreakfast` Cachix cache, and a pinned release tag substitutes from it. Add the cache to your `nix.settings` and `nix run`, the package and the overlay all fetch instead of building:

```nix
substituters = [ "https://codeforbreakfast.cachix.org" ];
trusted-public-keys = [ "codeforbreakfast.cachix.org-1:W96fHCqTzLZ7Vj2TKMMRLOkWzUn7N3LxKyBuF255XKg=" ];
```

The line `F` draws over the trees it put out of the way now says `N other trees`.

## Upgrading

**The overlay's `pkgs.beady-eye` is now built against this flake's nixpkgs rather than yours.** Your system carries this flake's nixpkgs closure alongside its own as a result. `pkgs.beady-eye-rebuilt` is the old behaviour, built against your nixpkgs, and compiles.

## Maintenance

Dependency bumps.

## Installing

```console
$ brew install codeforbreakfast/tap/bdi
```

`cargo install beady-eye` from crates.io if you would rather compile it. Or pin `github:CodeForBreakfast/beady-eye/v0.9.0` as a flake input and take the package or the overlay. Or take a binary from this page: one per platform, `.sha256` beside each, the Linux ones static. Apple has not been asked to sign the macOS ones, so a copy a browser downloaded needs `xattr -d com.apple.quarantine bdi` first.

The crate is `beady-eye`. The command is `bdi`.
