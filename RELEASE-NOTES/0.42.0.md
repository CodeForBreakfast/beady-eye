bdi 0.42.0

Minor release, **0.41.0 → 0.42.0**.

## Highlights

**The web view has a new look.** `bdi web` draws in its own palette, light and dark, with titles in a proportional face, and calls itself beady-eye. Each bead reads as a status mark, its title, then a small quiet id.

**The web view has a new bar.** On a desktop the top bar holds a views dropdown that counts what each view lists, a Ready switch, and a search field for a title or id. On a phone the same controls sit in a tab bar at the foot.

**Each project in the web view has a heading.** It shows the project's name, how long ago it was read in your own time zone, a bar of how many of its beads are done, its agents and its beads to check.

**Showing one tree in the web view says so.** A band above the tree reads "Showing only", names the bead, and offers "Show all trees".

**Creating or closing a bead no longer slows a refresh.** After a bead is created or closed, the view and `bdi watch` read only what changed, so they keep up with a busy tracker.

**A badge's literal colour shows as written in the web view.** It no longer changes with the theme when it happens to match a status colour.

## Maintenance

The container image's bd is built on current Go, which clears most of the fixable vulnerabilities a scan reports, plus dependency bumps.
