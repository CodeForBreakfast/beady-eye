bdi 0.39.0

Minor release, **0.38.1 → 0.39.0**.

## Highlights

**`v` opens views of beads that you name in your config.** Add a `[[views]]` entry with a name and one or more `[[views.select]]` tables, written with the same `when` and `unless` patterns as a badge. Each press of `v` shows the next view's unfinished beads in place of the tree, the most urgent first, and the press after the last view brings the tree back. Nothing changes until you add a view, and `docs/configuration.md` has an example.

## Maintenance

The container image now carries bd 1.3.2, plus other dependency bumps.
