bdi 0.43.1

Patch release, **0.43.0 → 0.43.1**.

## Highlights

**Homebrew and the container image move to 0.43.1.** 0.43.0 reached crates.io and GitHub, but it has no container image and Homebrew never offered it, so both go straight from 0.42 to this release.

**A screen reader names a web page's folds in words.** Folding a run of finished beads or a group no longer reads out the check mark or the warning sign first.

## Maintenance

The build of the bd that ships with bdi no longer depends on what the Go module proxy offers on the day.
