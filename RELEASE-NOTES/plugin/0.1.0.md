beady-eye plugin 0.1.0

First release of the beady-eye Claude Code plugin.

## Highlights

**A session can watch beads and be woken when they change.** The plugin gives a Claude Code session `watch`, `unwatch` and `watching` tools. A watched bead that changes status, becomes ready, is commented on or goes wakes the session with one message per batch of changes. A session's watches are kept across a restart.

**The session is told when nothing is listening.** When the watcher has been down for a minute, the session hears once which beads it cannot watch, and hears again when the watcher is back. A watched bead's tracker that stays unreachable for a minute is reported the same way. A watcher restarting for an upgrade or a config edit wakes nobody.

**Installing it.** The plugin needs Node and a `bdi watch` running on the same machine. Add the marketplace and install the plugin, then start each session with the plugin's channel allowed, or it is never woken:

```console
$ claude plugin marketplace add CodeForBreakfast/beady-eye#plugin-v0.1.0
$ claude plugin install beady-eye@beady-eye
$ claude --dangerously-load-development-channels plugin:beady-eye@beady-eye
```
