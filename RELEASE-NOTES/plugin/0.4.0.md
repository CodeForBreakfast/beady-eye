beady-eye plugin 0.4.0

Minor release, **0.3.0 → 0.4.0**.

## Highlights

**A session hears about the beads it is working on without watching them.** When a bead's `agent_session` metadata names a session, that session is told of each change to the bead as if it had watched it. It is also told about each pull request gate on that bead and the beads the gate holds back, so a pull request's reviews, checks and merge reach it. If your bdi config sets `agent_session_key` under `[join]`, the plugin reads that key instead.

**Those watches end on their own.** A bead stops being watched once it no longer names the session, or once it closes and the session has been told. `unwatch` leaves such a bead watched while the session still holds it. A bead the session also watched itself stays watched until the session unwatches it.

**Agents find the plugin's skill when they mean to subscribe.** The `using-beady-eye` skill's description now says it is for subscribing to a bead's changes instead of sleeping and reading the bead again.

## Upgrading

**Pin the marketplace to `plugin-v0.4.0`** as the README shows, and update the plugin. bdi and the plugin can be updated in either order.
