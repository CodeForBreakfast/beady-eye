beady-eye plugin 0.2.4

Patch release, **0.2.3 → 0.2.4**.

## Highlights

**The npm page shows the plugin's whole description.** npm cuts a description at 255 characters, so the page for 0.2.3 stopped mid-sentence. The description is now short enough to show in full. Nothing changes in how the plugin behaves.

**The plugin says it tells a session of a change, not that it wakes one.** A session hears of a change to a watched bead whether it is idle or busy, so the npm page, the marketplace listing, the skill and the instructions the session reads now say that.

**Updating.** Pin the marketplace to `plugin-v0.2.4` as the README shows, and update the plugin.
