beady-eye plugin 0.2.0

Minor release, **0.1.0 → 0.2.0**.

## Highlights

**A session is told how to use the plugin.** Every session that loads the plugin now learns what `watch`, `unwatch` and `watching` do, how a change reads when it arrives, and that a watch lasts until `unwatch`, across restarts. A new `using-beady-eye` skill covers what to watch, how to act on a change and when to unwatch.

**The server starts where npm holds back new releases.** Where npm's `min-release-age` is set, npm refused to start a newly released plugin server and the plugin failed to connect. The new optional `NPM_MIN_RELEASE_AGE` plugin setting sets that age for the plugin's server alone, and `0` starts a new release at once. Left unset, the age your `.npmrc` sets still applies.

**Updating.** Pin the marketplace to `plugin-v0.2.0` as the README shows, and update the plugin.
