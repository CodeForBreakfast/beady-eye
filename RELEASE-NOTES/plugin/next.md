beady-eye plugin 0.2.3

Patch release, **0.2.2 → 0.2.3**. Nothing changes in how the plugin behaves.

## Highlights

**A coming release can be tried as a candidate.** Before a release, a candidate such as `0.2.3-rc.1` can be published to npm under the `next` dist-tag and tagged `plugin-v0.2.3-rc.1` as a GitHub prerelease. A marketplace pinned to a release keeps installing that release, so nothing changes unless you pin the marketplace to a candidate's tag, as in `claude plugin marketplace add CodeForBreakfast/beady-eye#plugin-v0.2.3-rc.1`.

**Updating.** Pin the marketplace to `plugin-v0.2.3` as the README shows, and update the plugin.
