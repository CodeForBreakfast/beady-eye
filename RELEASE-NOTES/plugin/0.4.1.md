beady-eye plugin 0.4.1

Patch release, **0.4.0 → 0.4.1**.

## Highlights

**A session hears when it hands back a bead it was working on.** When a session stops naming itself on a bead and the bead goes back from in progress to open, the session is now told of that change before the watch ends. Before, the watch could end first and the change never arrived.

**A session hears about a tracker that cannot be reached when it first watches a bead there.** If the tracker was already unreachable when the watch began, the session could go without the message saying so. It now gets that message.

## Upgrading

**Pin the marketplace to `plugin-v0.4.1`** as the README shows, and update the plugin. bdi and the plugin can be updated in either order.
