beady-eye plugin 0.2.1

Patch release, **0.2.0 → 0.2.1**.

## Highlights

**A session waiting on a pull request now hears when it merges.** The `using-beady-eye` skill tells a session waiting on a pull request to watch the pull request's gh:pr gate, which closes on the merge, and the bead the gate blocks, which is commented on when the pull request closes without merging. Watching only the waiting bead missed the merge wherever a molecule held the gate. A session already watching only the waiting bead should add a watch on its gate.

**Updating.** Pin the marketplace to `plugin-v0.2.1` as the README shows, and update the plugin.
