beady-eye plugin 0.4.2

Patch release, **0.4.1 → 0.4.2**.

## Highlights

**A session in auto mode can use the plugin again.** Auto mode refused every call to `watch`, `unwatch` and `watching`, because the plugin changed each call after auto mode had reviewed it. The plugin no longer changes a call, and the three tools answer.

**A session still learns its new identity after `/clear` or `/resume`.** The watcher names the new session before the next tool call, as it did before.

## Upgrading

**Pin the marketplace to `plugin-v0.4.2`** as the README shows, and update the plugin. bdi and the plugin can be updated in either order.

## Maintenance

Dependency bumps and tests.
