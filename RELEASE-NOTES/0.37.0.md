bdi 0.37.0

Minor release, **0.36.0 → 0.37.0**.

## Highlights

**A bead other agents are watching is marked.** When an agent watches a bead with the Claude Code plugin's `watch` tool, the bead's row ends in `◉`. The bead window lists each watching agent by the name herdr shows for it, and counts any herdr cannot find in a pane. The agent working the bead is not listed as watching it.

**A bead stays with its agent when the agent moves to another pane.** Write the agent's Claude session id onto the bead as `agent_session`, beside `agent_pane`, and bdi shows the bead against whichever pane herdr finds that agent in. A pane reused by a new agent no longer takes on the bead of the agent that left it. A bead with only `agent_pane` is shown as before.

**bdi reports one agent claimed twice.** Two beads naming the same agent's session, or one session found in two live panes, now show as a conflict, and neither bead is given the agent.

## Upgrading

**The watch mark needs a Claude Code plugin newer than 0.2.4.** Older plugins do not say which agent is watching, so no bead is marked. Where no watcher answers for a bead's project, the bead window says who watches it is unknown.

**`join.agent_session_key` names the metadata key that holds the agent's session.** It defaults to `agent_session`. Set it only if your beads keep the session under another key.

**`--json` output names an agent's session.** Each agent carries its `agent_session`, its `source` can now be `agent_session`, and `conflicts` gains the kinds `several-beads-name-one-agent-session` and `agent-session-in-several-panes`.
