bdi 0.6.0

Minor release, **0.5.0 → 0.6.0**.

## Highlights

**A badge's `match` is a regular expression now**, anchored against the whole value, so `human` draws on `human` and not on `inhumane`. A `match` that is a plain word is unaffected. One holding a metacharacter — a `.`, a `+`, a bracket — no longer means the literal text it did in 0.5.0, so read the ones you have written.

**A badge can point somewhere.** Name the parts of the value with captures, and `link` rebuilds them into a URL that `render` can draw from as well: a `delivery_pr` of `CodeForBreakfast/beady-eye#57` becomes `⇢ #57` pointing at the pull request. A linked badge is drawn underlined and emitted as a terminal hyperlink, so a terminal that supports one opens the page on a click. Some want a modifier held — kitty opens on ctrl+shift+click, herdr on a plain one.

**A badge can take the colour of the bead's status.** `colour = "status"` draws it in the colour that bead's id is drawn in, so a ticket in another tracker reads as red on a blocked bead and orange on an in-progress one. It is the only colour a badge may name.

**A badge that cannot read its value says so.** A pattern that matches nothing, and a `link` template the value leaves half-filled, both used to take the reference off the row with no sign it had been there. Both now reach the row's notes. A badge with no `link` is a filter, so its silence stays silence.

**One project can draw a key differently from the rest.** `[[projects.badges]]` shadows the global `[[badges]]` by key, for a project whose values carry less than a shared pattern needs.

`docs/configuration.md` has a worked example for each shape a reference in metadata usually takes.

## Installing

```console
$ brew install codeforbreakfast/tap/bdi
```

`cargo install beady-eye` from crates.io if you would rather compile it. Or pin `github:CodeForBreakfast/beady-eye/v0.6.0` as a flake input and take the package or the overlay. Or take a binary from this page: one per platform, `.sha256` beside each, the Linux ones static. Apple has not been asked to sign the macOS ones, so a copy a browser downloaded needs `xattr -d com.apple.quarantine bdi` first.

The crate is `beady-eye`. The command is `bdi`.
