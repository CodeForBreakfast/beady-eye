bdi 0.5.0

Minor release, **0.4.0 → 0.5.0**.

## Highlights

**The wheel moves the view, not the selection.** A notch used to move the selection and drag the window along after it. It now scrolls the view and leaves the selection where you put it. `[tui]`'s new `wheel_notch_lines` sets how far a notch goes and defaults to three; a trackpad wants it lower.

**The socket notice stops sitting there.** On macOS, where there is no `$XDG_RUNTIME_DIR`, it held a row of the foot for the whole session. Both socket notices now retire a minute after startup. The refusal is still written to standard error.

Nothing to do on an existing install.

## Installing

```console
$ brew install codeforbreakfast/tap/bdi
```

`cargo install beady-eye` from crates.io if you would rather compile it. Or pin `github:CodeForBreakfast/beady-eye/v0.5.0` as a flake input and take the package or the overlay. Or take a binary from this page: one per platform, `.sha256` beside each, the Linux ones static. Apple has not been asked to sign the macOS ones, so a copy a browser downloaded needs `xattr -d com.apple.quarantine bdi` first.

The crate is `beady-eye`. The command is `bdi`.
