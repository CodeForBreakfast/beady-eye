bdi 0.14.0

Minor release, **0.13.0 → 0.14.0**.

## Highlights

**A pinned bead is finished work, not open work.** bd keeps a pinned bead indefinitely and never counts it as work, but `bdi` read the status as unrecognised, so each one turned up as a root of its own with an anomaly on its row. It now draws as `⊙` in its own colour and folds away with the closed beads. The fold line and the `n/m` count say finished rather than closed, because they count both.

**A hooked bead is work in flight.** It draws as bd's own `◇`, is found as a root, and counts as unfinished, where it used to draw `?` with a note saying the status was unknown.

**A mistyped config key is refused rather than ignored.** A key no table declares used to be read as the default without a word, so a `refresh_second` left `bdi` refreshing on a number you never chose. The refusal names the key and its table. At startup `bdi` will not run until you fix the file. While running, the config already in force stays in force and the foot says so. If your config has been carrying a typo, this release is when you find out.

**A producer can say it is watching a project with nothing to report.** A `covered <project>` line on the inbound socket vouches for the project without costing a read. A project that does not poll wears `?` beside its name once `[changes] covered_for_seconds` passes with no read and no covered line, so a producer that has died no longer looks the same as a quiet tracker. The default is 60 seconds. A polled project never lapses, so nothing changes unless you run with `poll = false` or `--no-poll`. [docs/configuration.md](https://github.com/CodeForBreakfast/beady-eye/blob/main/docs/configuration.md) has the protocol.

**An epic's children draw in numeric order,** so `.2` comes before `.10`.

**A tracker with a live claim is no longer read in full on nearly every poll.** From beads 1.3.0 a claim's heartbeat moved the change probe each time. It no longer does. A `[[badges]]` key naming `heartbeat_at` or `lease_expires_at` now updates only when something else in the tracker moves.

**A root whose tracker would not read keeps the selection across a refresh,** and `s` on its row no longer puts a spine rule in force there.

## Breaking: `counts.closed` under `--json`

This one is for you only if something reads `bdi --json`. `counts.closed` is now `counts.finished`, and it counts pinned beads as well as closed ones.

## Maintenance

The flake no longer serves Intel Macs, which take the Homebrew or release binary instead. Also dependency bumps, CI, tests, docs and internal improvements.
