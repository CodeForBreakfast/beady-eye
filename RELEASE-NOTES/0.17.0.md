bdi 0.17.0

Minor release, **0.16.0 → 0.17.0**.

## Highlights

**Install bdi as a herdr plugin.** `herdr plugin install CodeForBreakfast/beady-eye` gives a herdr user bdi without a Rust toolchain, downloading the matching release build. A key bound to `codeforbreakfast.beady-eye.open` opens it in a split beside the focused pane.

**Plain-English messages.** Notices, conflict lines and error messages read as ordinary sentences instead of compressed clauses, and the config and socket errors now say what to change.
