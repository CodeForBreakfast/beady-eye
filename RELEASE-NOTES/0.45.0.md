bdi 0.45.0

Minor release, **0.44.0 → 0.45.0**.

## Highlights

**bdi draws agents running in the herdr app as well as in herdr.** Add an `[hc]` table to your config and bdi reads the app's terminals through `hc`, showing them in a session called `herdr app` beside herdr's own. A terminal joins a bead by the address `hc ls` prints, such as `t7`, or by the agent session in the terminal label that `session_label` names. Without the table bdi never runs `hc`, so there is nothing to do beyond upgrading if you do not use the app.

**`bdi web` no longer says every claimed bead has no agent on it.** A claimed bead's page now says its agent is unknown. `bdi watch` stops reporting those claims as having no agent too.
