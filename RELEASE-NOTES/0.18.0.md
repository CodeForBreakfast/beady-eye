bdi 0.18.0

Minor release, **0.17.0 → 0.18.0**.

## Highlights

**A blocker in another project is drawn as the bead it is.** Give a project in your config a `prefix` and bdi knows which beads it holds. When you open bdi on one bead and that bead is blocked by a bead in another configured project, bdi reads that project too and draws the blocker with its title and status, then keeps watching it. Under `--project`, bdi reads nothing extra and reports the blocker as held by that project, which the JSON output marks `held-by-unread`.

**A config with no `prefix` draws exactly as before.** Add `prefix = "<bead prefix>"` to a `[[projects]]` entry to use the new behaviour. Nothing else needs changing.
