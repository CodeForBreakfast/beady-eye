bdi 0.18.0

Minor release, **0.17.0 → 0.18.0**.

## Highlights

**bdi reads a blocker's project when it needs to.** When a bead's blocker is in a configured project bdi isn't reading, bdi now reads that project and shows the blocker with its title and status, instead of reporting that it is in a project bdi hasn't read. bdi keeps watching that project from then on. Under `--project`, bdi still reads only the projects you named.

**You can set a project's bead prefix in config.** Add `prefix = "<bead prefix>"` to a `[[projects]]` entry. bdi uses the prefix to know which project holds a blocker, and reads a blocker's project only when that project states its prefix. The setting is optional, and a config without it behaves as before.
