bdi 0.30.0

Minor release, **0.29.0 → 0.30.0**. Nothing needs changing to upgrade.

## Highlights

**A live claim is no longer an orphan on a machine its seat does not run on.** A claim whose lease is live, or that sits beneath a bead holding one, counts as worked, so every machine reading the tracker agrees about it. The pane is still drawn only on the machine where it runs. A claim stays live only while its holder renews it with `bd heartbeat`. `--beads` now lists each bead's `assignee` and `lease_expires_at`.

**`bdi bd` passes `comments add` through.** `bdi bd <project> comments add <id> -- <text>` puts a comment on a bead in that project's tracker, alongside `human respond` and `defer`.

**`bdi gates` settles a `gh:run` gate.** A gate on a GitHub Actions workflow run closes once the run succeeds or is skipped.

**The container image reaps orphaned processes.** The image runs `bdi` under `tini`, so a `bdi gates` container no longer collects zombie `bd` processes.
