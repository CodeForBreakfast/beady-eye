bdi 0.19.0

Minor release, **0.18.1 → 0.19.0**.

## Highlights

**`bdi --beads` lists each bead's labels and description.** Every bead now carries `labels` (an empty array when it has none) and `description` (`null` when it has none), as bd reported them. A reader can pick out the beads labelled `human` across every project from one query. The set of beads listed is unchanged, so there is nothing to do.

**`bdi bd <project> human respond` records an answer in that project's tracker.** It runs `bd human respond` against the tracker of a project your config names, with that project's directory, wrapper and credential, and bd's output and exit code reach you unchanged. It is the one command bdi passes through and it takes no flag but `-r`/`--response`, so a permission rule on `bdi bd <project>` keeps a caller to that project. Nothing to do unless you want it.

## Maintenance

Labels now draw on a row of their own under a bead's name, a project whose tracker refused no longer stops the tree stepping on, and the docs state what bdi owns and leaves out.
