bdi 0.27.1

Patch release, **0.27.0 → 0.27.1**. Nothing needs changing to upgrade.

## Highlights

**bdi always quits.** Told to quit by `q` or by a signal, on a terminal that has stopped taking its output, bdi used to hang for ever. It now leaves within three seconds, exiting with status 1 and leaving the screen as it is. On a Mac, a terminal left this way discards anything written to it until the next key is typed.

**The watcher hears every change.** `bdi watch` takes the changes socket from whichever view held it, a view from an older release included, so a change pushed there reaches the watcher at once. A one-shot run beside an answering watcher no longer sometimes reads its tracker for itself.

**More of bdi works on macOS.** A project whose own directory supplies `direnv` is read rather than reported unreadable. A project with no git whose tracker bd names through a symlink is rooted at its tree rather than at the directory bdi started in.

**The help says which projects to read.** `bdi --help` now ends with a section saying when each scope fits: the directory's project, a named bead, `--project` and `--all-projects`. Every project a run reads costs its own reads, so it helps you read the fewest that answer the question.
